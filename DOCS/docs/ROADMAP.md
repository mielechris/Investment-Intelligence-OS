# Investment Intelligence OS — Roadmap

## Current Foundation

- IIOS V1.0 remains the frozen governed baseline on `main`.
- The governed eight-agent chain, Investment Committee, deterministic Risk, Capital Control, Paper Authorization, and governed Paper Execution remain fail-closed.
- Batch 7 Grok/xAI intelligence remains experimental and research-only until its value-proof gates are satisfied.
- Batch 8 paper-portfolio, entry-readiness, position-sizing, and governed execution-path work remains the immediate build priority.

## Batch 7 — Grok Experimental Intelligence

Status: **IN VALUE PROOF**

Built capabilities include:

- xAI / Grok adapter
- X Search / social intelligence lane
- social/narrative firewall
- citation identity repair
- independent-account source diversity
- Grok vs native-IIOS A/B harness
- prospective discovery lead-time measurement
- false-positive accounting
- Grok shadow ledger
- model scorecard
- autonomous forward-value observations

Governance remains unchanged: Grok has no capital authority, no position-sizing permission, no paper-order permission, no automatic promotion into normal IIOS runs, and no live-execution authority.

## Batch 8 — Governed Paper Portfolio & Execution Path

Status: **ACTIVE**

Continue the existing Batch 8 sequence through generic position sizing, entry readiness, governed Paper Authorization, and Paper Order handoff while preserving the existing fail-closed execution boundary.

## Batch 9 — Kimi K3 Deep-Context Intelligence

Status: **PLANNED**

Objective: add Kimi K3 as a bounded research-only model lane inside IIOS.

Primary use cases:

- long-context SEC filings
- earnings-call transcripts
- historical reports and research archives
- cross-document synthesis
- large evidence packets
- image/chart-aware research where useful
- deep-context fundamental and historical analysis

Requirements:

- preserve IIOS provenance, timestamps, citations, evidence lineage, uncertainty, and auditability
- run Kimi as an independent research engine rather than an execution authority
- no capital authority
- no position-sizing authority
- no Paper Authorization authority
- no paper-order permission
- no live execution

## Batch 10 — IIOS Model Arena

Status: **PLANNED**

Objective: expand the existing Grok-vs-native-IIOS A/B framework into a governed multi-model intelligence arena.

### Core Arena

Run the same governed case/evidence packet independently through:

1. IIOS / OpenAI native reasoning
2. Grok / xAI
3. Kimi K3

Then compare the outputs before or alongside Committee synthesis.

### Measurements

Track each model by task type using:

- thesis agreement and disagreement
- evidence quality and source fidelity
- citation accuracy
- discovery lead time
- false-positive rate
- confidence calibration
- falsifier quality
- realized governed paper outcomes
- differentiated-action P&L attribution when legitimately available
- performance by research category

### Model Specialization Scorecards

IIOS should learn which model performs best for:

- breaking news / X / narrative signals
- policy and geopolitical events
- deep fundamental research
- long-document analysis
- historical-pattern reasoning
- adversarial / skeptic review
- cross-source synthesis
- committee support

### Governance

The models remain research engines. IIOS governance stays authoritative.

No model may bypass:

- evidence gates
- Investment Committee
- deterministic Risk
- Capital Control
- Paper Authorization
- governed execution controls

Promotion of any model lane into normal IIOS operation requires explicit value proof and a separate governance decision.

## Sequencing

1. Finish Batch 7C Grok value proof without weakening safety or source-quality gates.
2. Finish and freeze the Batch 8 governed paper-portfolio / execution-path work.
3. Begin Batch 9 Kimi K3 Deep-Context Intelligence.
4. Build Batch 10 IIOS Model Arena using the existing Grok A/B infrastructure as the foundation.
5. Keep all new model lanes in shadow/research mode until measured performance justifies promotion.
