# ADR-009 — Preserve Dissent

**Status:** ACCEPTED  
**Decision owner:** Founder / Architecture  
**Initial decision date:** 2026-08-20  
**Applies to:** V0.1  
**Supersedes:** None  
**Superseded by:** None

---

## Context

Simple averaging can hide materially different assumptions and create false consensus.

## Decision Drivers

- correctness;
- auditability;
- risk control;
- implementation speed;
- future institutional readiness;
- reversibility;
- operational simplicity.

## Options Considered

1. Average agent scores
2. Force consensus
3. Persist dissent and unresolved assumptions

## Decision

Committee records dissent rather than averaging it away.

## Rationale

Disagreement itself contains information and improves postmortem learning.

## Positive Consequences

- Transparent uncertainty
- Better red-team signal
- Improved calibration

## Negative Consequences / Trade-Offs

- More complex committee output
- May reduce apparent decisiveness
