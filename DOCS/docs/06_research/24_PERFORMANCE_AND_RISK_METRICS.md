# Performance and Risk Metrics

## Return Metrics

- gross return;
- net return;
- benchmark return;
- excess return;
- annualized return where sample supports it.

## Risk Metrics

- volatility;
- maximum drawdown;
- recovery time;
- downside deviation;
- tail loss;
- gross exposure;
- net exposure;
- concentration;
- causal-cluster exposure.

## Trade Metrics

- number of trades;
- hit rate;
- average win;
- average loss;
- payoff ratio;
- expectancy;
- turnover;
- average holding period;
- slippage;
- fees.

## Signal Metrics

- coverage;
- precision;
- recall where applicable;
- calibration;
- confidence-bucket performance;
- false-positive rate;
- no-trade rate.

## Research Metrics

- sample size;
- independent event count;
- regime distribution;
- parameter sensitivity;
- cost sensitivity;
- capacity.

## Reporting Rule

No single metric may define success.
