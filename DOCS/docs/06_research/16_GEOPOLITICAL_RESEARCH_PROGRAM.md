# Geopolitical Research Program

## Objective

Test market transmission from war, sanctions, diplomacy, trade routes, elections, and neighboring-country policy.

## Event Classes

- escalation;
- de-escalation;
- ceasefire;
- sanctions;
- sanctions relief;
- export controls;
- shipping-lane disruption;
- border restriction;
- trade agreement;
- political transition.

## Required Branches

For high-impact events:

- base case;
- escalation case;
- de-escalation case.

## Research Questions

- Which commodities react first?
- Which sectors mean-revert after initial shock?
- How persistent are FX and rate effects?
- How does existing positioning affect reaction?
- When does shipping disruption matter more than headline severity?

## Controls

- concurrent macro events;
- oil/gas moves;
- dollar;
- volatility regime;
- market-wide risk-off moves.
