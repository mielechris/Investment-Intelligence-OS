# Event Study Framework

## Purpose

Measure market behavior around defined event classes.

## Required Event Definition

Specify:

- event type;
- inclusion criteria;
- exclusion criteria;
- event timestamp;
- duplicate handling;
- policy stage;
- geography;
- source quality;
- event severity.

## Windows

Define:

- estimation window;
- pre-event window;
- event window;
- post-event window.

## Benchmarks

Use:

- broad market;
- sector;
- factor;
- commodity;
- rate;
- currency;
- custom matched control.

## Overlapping Events

Overlapping events must be:

- excluded;
- clustered;
- controlled;
- or explicitly modeled.

## Outputs

Report:

- average abnormal return;
- median abnormal return;
- distribution;
- hit rate;
- maximum favorable excursion;
- maximum adverse excursion;
- volatility response;
- volume response;
- sample size;
- confidence interval where appropriate.

## Required Breakdowns

- regime;
- event severity;
- policy implementation stage;
- sector;
- asset class;
- source quality;
- surprise magnitude.

## Failure Rule

A statistically or economically weak event class must not be promoted merely because a small subset looks attractive.
