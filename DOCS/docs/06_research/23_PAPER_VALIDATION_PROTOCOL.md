# Paper Validation Protocol

## Purpose

Validate research in forward time using frozen or versioned strategy logic.

## Minimum Requirements

A paper strategy must record:

- signal time;
- information cutoff;
- strategy version;
- model/prompt version;
- risk decision;
- expected fill;
- actual simulated fill;
- costs;
- exit rule;
- outcome;
- postmortem.

## Evaluation

Track:

- realized hit rate;
- benchmark-relative return;
- drawdown;
- turnover;
- calibration;
- slippage;
- no-trade frequency;
- missed opportunities;
- failure modes.

## Freeze Rule

Material strategy changes create a new version and restart or separately track forward validation.

## Promotion

Paper performance alone is not sufficient.

Also require:

- stable operations;
- acceptable risk behavior;
- execution realism;
- research integrity;
- no unresolved critical data issues.
