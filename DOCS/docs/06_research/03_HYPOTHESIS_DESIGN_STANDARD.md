# Hypothesis Design Standard

Every hypothesis MUST include:

## Identity

- hypothesis ID;
- version;
- title;
- owner;
- created date.

## Falsifiable Statement

Format:

> Under conditions X, event/state Y should cause measurable outcome Z over horizon H, relative to benchmark B.

## Causal Mechanism

List:

- cause;
- intermediate steps;
- asset impact;
- expected sign;
- expected lag.

## Counter-Chain

At least one plausible alternative mechanism.

## Asset Expression

Identify:

- direct instrument;
- sector basket;
- commodity;
- rate;
- currency;
- crypto;
- derivative;
- watch-only expression.

## Horizon

Define:

- intraday;
- 1–5 sessions;
- 1–4 weeks;
- 1–6 months;
- longer-term.

## Success Metric

Examples:

- benchmark-adjusted return;
- hit rate;
- information coefficient;
- drawdown-adjusted return;
- forecast calibration.

## Failure Metric

Define what invalidates the edge.

## Required Data

List every source and point-in-time requirement.

## Pre-Registration

Before final validation, freeze:

- hypothesis wording;
- feature set;
- primary metric;
- benchmark;
- holdout;
- main parameters.

Changes require a new version.
