# Research Lifecycle

## Lifecycle States

```text
IDEA
REGISTERED
EXPLORATORY
HISTORICALLY_TESTED
VALIDATED_OUT_OF_SAMPLE
PAPER_MONITORING
PROMOTED
REVISED
PAUSED
REJECTED
RETIRED
```

## Stage 1 — Idea

An informal observation.

No code or strategy promotion yet.

## Stage 2 — Registered Hypothesis

Must include:

- falsifiable statement;
- causal chain;
- counter-chain;
- assets;
- horizon;
- expected lag;
- benchmark;
- success metric;
- failure metric;
- required data.

## Stage 3 — Exploratory

Allowed:

- descriptive statistics;
- data inspection;
- event clustering;
- simple plots;
- preliminary feature exploration.

Not allowed:

- presenting exploratory results as validated edge.

## Stage 4 — Historical Test

Requires point-in-time dataset and baseline.

## Stage 5 — Validation

Requires:

- different time period or cross-section;
- costs;
- robustness;
- sensitivity;
- regime analysis.

## Stage 6 — Holdout / Walk-Forward

No repeated tuning on the same final set.

## Stage 7 — Paper Monitoring

Strategy generates real-time paper decisions using frozen or versioned logic.

## Stage 8 — Promotion

Requires research review and risk review.

## Stage 9 — Revision

Material logic changes create new strategy version.

## Stage 10 — Retirement

Strategy is removed from active use while history is preserved.
