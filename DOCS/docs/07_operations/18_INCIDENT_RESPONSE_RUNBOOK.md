# Incident Response Runbook

## Severity

### SEV-1

Integrity or safety failure that may invalidate portfolio/risk state.

Examples:

- live-route exposure;
- accounting corruption;
- security compromise;
- missing audit lineage;
- duplicated fills.

### SEV-2

Major degradation without confirmed integrity loss.

### SEV-3

Limited operational defect.

## Response

1. detect;
2. classify;
3. activate stand-down if needed;
4. preserve evidence;
5. assign owner;
6. contain;
7. diagnose;
8. recover;
9. verify;
10. document root cause;
11. define corrective action;
12. close incident.

## Incident Record

Must include:

- timeline;
- affected components;
- affected decisions;
- affected data;
- root cause;
- recovery;
- prevention;
- owner;
- closure.
