# Daily Operating Runbook

## Morning

- verify system health;
- verify source freshness;
- ingest overnight events;
- ingest market/macro data;
- update world state;
- run event triage;
- generate reasoning;
- run specialist agents;
- run skeptic;
- convene committee;
- evaluate risk;
- generate paper orders or no-trade;
- publish daily briefing.

## Intraday

- monitor critical events;
- update scheduled macro releases;
- watch invalidation conditions;
- monitor risk;
- monitor data freshness;
- review critical alerts.

## Post-Close

- reconcile orders/fills;
- mark end-of-day portfolio snapshot;
- close or roll expired paper items;
- record outcome changes;
- schedule postmortems;
- generate daily audit summary;
- verify backup.

## Daily Completion Conditions

The day is complete only when:

- paper accounting reconciles;
- critical source-health issues are recorded;
- unresolved incidents are visible;
- journal is updated;
- backup status is known.
