# Cost and Usage Operations

## Cost Categories

- model calls;
- embeddings;
- market data;
- news/research data;
- storage;
- compute;
- observability;
- future broker/data fees.

## Measurement

Track cost by:

- agent;
- workflow;
- source;
- strategy;
- research run;
- environment.

## Controls

- per-run model budget;
- daily model budget;
- concurrency limits;
- context-size limits;
- retrieval limits;
- batch embeddings;
- cache where rights allow;
- avoid duplicate source fetches.

## Cost Alert

Raise warning when:

- model spend spikes;
- source usage exceeds plan;
- research run is unusually expensive;
- repeated retries consume budget.

## Principle

Higher cost must demonstrate higher decision value.
