# Committee Operations

## Session Preconditions

- thesis exists;
- required evidence exists;
- source cutoff exists;
- required specialist views completed;
- skeptic completed;
- critical data healthy.

## Session Procedure

1. create committee session;
2. verify required views;
3. inspect dissent;
4. request missing evidence if necessary;
5. run bounded debate;
6. produce disposition;
7. record unresolved assumptions;
8. set expiry;
9. route candidate to Risk Engine.

## No-Trade

No-trade is complete only when reason is journaled.

## Expired Decision

Expired committee decisions cannot create new risk.

A new session is required after material state changes.
