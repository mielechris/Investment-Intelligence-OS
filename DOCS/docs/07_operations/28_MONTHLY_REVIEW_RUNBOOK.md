# Monthly Review Runbook

## Research Review

- promoted strategies;
- paused strategies;
- retired strategies;
- out-of-sample stability;
- regime performance.

## Portfolio Review

- monthly return;
- drawdown;
- recovery;
- concentration;
- capacity assumptions.

## Model Review

- calibration;
- drift;
- cost;
- provider reliability;
- prompt changes.

## Source Review

- rights;
- freshness;
- reliability;
- duplicate content;
- source value.

## Architecture Review

Ask:

- has scale changed?
- is any module a bottleneck?
- is complexity earning its place?
- are deferred architecture decisions now ready?

## Governance Review

- open ADRs;
- risk register;
- incidents;
- access;
- backups;
- recovery tests.

## Output

Create monthly review artifact with decisions and follow-up tickets.
