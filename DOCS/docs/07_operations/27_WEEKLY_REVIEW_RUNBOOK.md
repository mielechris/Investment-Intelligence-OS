# Weekly Review Runbook

## Review

### Performance

- paper return;
- drawdown;
- turnover;
- benchmark-relative result;
- strategy-level results.

### Decision Quality

- no-trade quality;
- thesis invalidations;
- false positives;
- missed opportunities;
- causal-chain failures.

### Agents

- unsupported claims;
- calibration;
- abstention;
- cost;
- latency.

### Data

- source failures;
- stale periods;
- revisions;
- quarantine cases.

### Risk

- vetoes;
- near-limit conditions;
- concentration;
- theme overlap.

### Operations

- incidents;
- retries;
- backup status;
- release issues.

## Output

Weekly review must create:

- summary;
- action list;
- hypothesis updates;
- tickets;
- risk-review items.
