# IIOS Living Wall — Auction Edition asset provenance

All raster character artwork used by the Auction Edition is reused from the repository's established V7.5/V7.5.1/V7.5.2 IIOS Family Factory asset set under `FRONT END/src/assets/`. The source notes and verification fragments remain in `FRONT END/src/assets/v75/`.

No third-party stock art, generated replacement art, blockchain claim, NFT claim, or ownership assertion was added. Architectural scenery, lighting, typography, machinery, and particles are original CSS shapes authored in this repository. Runtime data remains presentation-only and governed by `living_wall_truth.v1`.
