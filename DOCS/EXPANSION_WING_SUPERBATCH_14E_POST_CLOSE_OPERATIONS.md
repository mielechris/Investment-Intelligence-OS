# Superbatch 14E: Post-Close Operations Controller

The controller joins the reviewed closing-session, candidate-enrichment, credit-accounting, and primary-source contracts. It is disabled by default and has no scheduler, network client, Keychain access, broker, or ledger route.

The controller stops before candidate work unless the closing-session evidence is complete and hash-valid. A successful enrichment result without source attestations becomes `AWAITING_PRIMARY_SOURCES`. Fully bound, rights-approved and human-approved SEC or issuer evidence becomes `READY_FOR_GOVERNED_CASE_DRAFT` only.

The durable browser projection contains counts, state, session date, fixed failure category, and false authority flags. It excludes tickers, company facts, source text, URLs, paths, credentials, ciphertext, recommendations, prices, targets, position sizes, and instructions.

Activation requires a separately reviewed runtime procedure using actual sanitized 9H and scanner artifacts. Preview installation and governed case persistence remain separate checkpoints.
