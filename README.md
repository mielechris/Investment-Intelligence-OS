# Investment Intelligence OS

## Experience track preview

On branch `feature/iios-experience-x0-x1`, run:

```bash
python3 scripts/apply_experience_x2.py
```

The preview gate mounts the X0/X1 command center, X2 Living Factory Floor, and the canonical ledger-event rail into the local frontend, then runs `npm run build`. Unknown rooms remain unplaced and unknown ledger event types remain ignored rather than creating synthetic movement.
